Segurança da janela

Cada item tenta sair do app de um jeito. O que acontece está ao lado de cada um e, em Sensores, o que a página enxergou.

Navegação e janelas novas

  • Link para example.com fora da lista: abre no navegador do sistema
  • Link com target="_blank" janela nova nunca abre: vai para o navegador
  • idem
  • gesto do usuário: navegador do sistema
  • Link para example.org está em allowNavigation: navega nesta janela (volte com Alt+←)
  • mailto: abre o programa de e-mail
  • file:///C:/Windows/notepad.exe cancelado, nada é executado
  • Página do app navega nesta janela
  • Página do app com target="_blank" ignorado: não abre janela

Sensores

Clique com o botão direito aqui, aperte F5, Ctrl+R, Ctrl+U, Ctrl + + / - ou gire a roda com Ctrl.

Teclas recebidas pela página
—

Com browserKeys: false, F5, Ctrl+R, Ctrl+U e Ctrl + +/-/0 não chegam à página (os carregamentos não sobem). Uma tecla comum, como x, chega. O evento contextmenu chega, mas, com contextMenu: false, o menu nativo (Voltar, Atualizar, Salvar como...) não aparece.
