Plugin clipboard

Área de transferência do Windows pelo Delphi: funciona a partir de qualquer código da página, sem a permissão que a Clipboard API do navegador pede fora de um clique, e com Unicode completo (emoji inclusive), apesar de o Delphi 7 ser ANSI.

1. Copiar texto (writeText)

Cole no Bloco de Notas para conferir.

2. Ler (readText)

Copie algo em outro programa e clique em Ler.

(nada lido ainda)

3. Copiar HTML (writeHtml)

Negrito, itálico, vermelho e uma lista:
  • um
  • dois 😀

Cole no Word ou no WordPad: a formatação vai junto. No Bloco de Notas, entra o texto alternativo (altText).
